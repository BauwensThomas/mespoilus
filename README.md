# Mes Poilus

Site de référence francophone dédié aux animaux de compagnie : conseils vétérinaires, fiches races, outils pratiques, adoption entre particuliers et boutique de produits animaliers.

**Marchés ciblés :** Belgique, France, Suisse, Luxembourg, Canada francophone, Afrique francophone.

---

## Ce projet n'est pas open source

Le code source de ce dépôt est privé et n'est pas destiné à être réutilisé, forké ou déployé par des tiers.
